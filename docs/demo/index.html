Orca demo

Type an English sentence. Orca proposes a derivation with a neural tagger, the English Resource Grammar checks it by replay and repairs it where it fails, the grammar's ranking model picks among the accepted derivations, and the result is a complete grammar analysis with its meaning (MRS).
