# Theory log

Records of where existing syntactic theory (HPSG first, then others) strains,
what the alternatives are, and what we propose. Revising the theory is a
long-term, secondary goal of this project; the primary goal is fast,
inspectable HPSG-style parsing and grammars for many languages. Entries are
kept even when a proposal is rejected.

One file per entry, named `NNNN-short-slug.md`, with these sections:

- **Strain**: where the current analysis is awkward, stipulative, or fails.
- **Evidence**: data and sources (with chapter and page references).
- **Competing analyses**: what different frameworks or authors say.
- **Consequence for our parser and grammars**: what it constrains.
- **Proposal and test**: the revision, and a measurable prediction.
- **Status**: open | tested | adopted | rejected, with the reason.
